# OMR 가채점 프로그램

복합기로 스캔한 답안지 PDF를 업로드하면 마킹을 자동 판독하고,
명렬표와 대조해 인적사항 오류를 잡아낸 뒤, 정답·배점으로 가채점해
엑셀 리포트로 출력하는 프로그램입니다.

## 웹 버전 (설치 불필요)

아래 주소에서 바로 사용하세요:

**https://omr-gr-gfcyhbfkuxntfunwydjmrn.streamlit.app/**

## 로컬 실행 방법

**모든 처리는 이 PC에서만 이루어집니다. 스캔 이미지가 외부로 전송되지 않습니다.**

### Windows (학교 PC)
1. Python 3.10 이상 설치 (python.org)
2. 이 폴더에서 `run.bat` 더블클릭
3. 웹 브라우저가 열리면 사용 시작

### Mac/Linux
```bash
chmod +x run.sh
./run.sh
```

## 사용 흐름 (6단계)

1. **세션**: 모의고사 세션 만들기 (예: 2026-09-고2-모평)
2. **양식 캘리브레이션** (교시별 1회):
   - 기준 답안지 1장 업로드 → 자동 영역 찾기
   - 검출된 영역(답안/수험번호/성명) 확인·수정 → 템플릿 저장
   - 답안지는 모의고사마다 조금씩 바뀌므로 교시별로 1회씩 수행
3. **스캔 PDF 판독**: 복합기 스캔 PDF 업로드 → 일괄 판독
4. **명렬표**: 원본 명렬표 엑셀 업로드 (수험번호/성명 컬럼)
5. **정답·배점**: 정답 엑셀 업로드 (문항/정답/배점 컬럼)
6. **결과**: 가채점 실행 → 오류 확인 → 엑셀 다운로드

## 판정 종류

- 정상
- 수험번호 미기재 / 복수표기 (몇 번째 자리인지 표시)
- 명렬표에 없는 번호 (1자리 오마킹 후보 제안)
- 수험번호 오류 시 후보 번호 제안 (명렬표 패턴 매칭)
- 중복 제출 (같은 번호 답안지 2장 이상)
- 미제출 (명렬표에는 있으나 답안지 없음)
- 답안 미기재 / 복수표기 (문항별)

## 엑셀 출력 시트

- 개인별점수: 수험번호, 성명, 점수, 문항별 O/X/미기재/복수표기
- 문항분석: 문항별 정답률
- 오류리스트: 모든 오류 한눈에
- 명렬표대조: 인적사항 대조 상세
- 정답및배점: 적용된 정답·배점

## 파일 구조

```
app/
  app.py              Streamlit UI
  omr/
    pdfio.py          PDF 렌더링, 기울기 보정
    detect.py         버블 검출
    template.py       양식 템플릿 (JSON)
    read.py           마킹 판독
    roster.py         명렬표 대조
    key.py            정답·배점 로더
    scoring.py        채점 + 엑셀 리포트
    pipeline.py       일괄 처리 파이프라인
  sessions/           세션별 템플릿·결과 저장
  requirements.txt
  run.sh / run.bat
```

## 주의사항

- 스캔은 200dpi 이상 권장 (복합기 기본 설정이면 충분)
- 기울어진 스캔은 자동 보정되나, 심하게 기울면 수동 확인 권장
- 캘리브레이션은 빈 답안지 또는 작성된 답안지 모두 가능
- 수험번호는 버블 마킹 기준, 손글씨는 참고용
